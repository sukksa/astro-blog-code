# 动词分类与基本活用

日语动词按活用规则分为一类、二类和三类。动词的辞书形是判断类别的基础形式；确定类别后，才能按规则构成各种活用形。本文整理 11 种常用形式。活用形式本身只表示形态，具体意义和句法功能还要结合后续表达判断。

## 动词分类

### 一类动词

一类动词的辞书形词尾为「う」段假名，即「う、く、ぐ、す、つ、ぬ、ぶ、む、る」之一。

| 辞书形 | 词尾 |
| --- | --- |
| 買う | う |
| 書く | く |
| 泳ぐ | ぐ |
| 話す | す |
| 待つ | つ |
| 死ぬ | ぬ |
| 遊ぶ | ぶ |
| 読む | む |
| 帰る | る |

### 二类动词

二类动词辞书形以「る」结尾，且「る」前一个假名通常在「い」段或「え」段。

| 辞书形 | 「る」前的假名 |
| --- | --- |
| 見る | み（い段） |
| 起きる | き（い段） |
| 食べる | べ（え段） |
| 寝る | ね（え段） |

这个判断条件有例外。「帰る、入る、走る、知る、切る」等虽然符合外形，但属于一类动词；应结合ます形或词典确认并记忆。

### 三类动词

三类动词包括「する」及其复合动词，以及「来る」。

| 辞书形 | ます形 |
| --- | --- |
| する | します |
| 勉強する | 勉強します |
| 来る（くる） | 来ます（きます） |

判断时先检查是否为「する」「来る」及其复合形式；其余动词再按辞书形词尾判断一类或二类。

## 辞书形

辞书形是词典收录动词时使用的基本形，如「書く、食べる、する、来る」。辞书形同时也是简体非过去肯定形式。

> 毎晩、本を読む。

每天晚上看书。

辞书形用于判断动词类别，也常接续其他语法表达。它与「普通形」不同：普通形是范畴，包含辞书形、ない形、た形等简体形式。

## ます形

ます形是礼貌体形式。各类动词的构成如下：

| 类别 | 构成 | 例子 |
| --- | --- | --- |
| 一类 | 词尾改为同一行「い」段＋ます | 書く→書きます；読む→読みます |
| 二类 | 去掉「る」＋ます | 食べる→食べます；見る→見ます |
| 三类 | する→します；来る→来ます（きます） | 勉強する→勉強します |

ます形的否定和过去形式为「ません、ました、ませんでした」。

> 先週、図書館で本を読みました。

上周在图书馆读了书。

## ない形

ない形表示简体否定，也用于接续其他表达。

| 类别 | 构成 | 例子 |
| --- | --- | --- |
| 一类 | 词尾改为同一行「あ」段＋ない；「う」改为「わ」 | 書く→書かない；買う→買わない |
| 二类 | 去掉「る」＋ない | 食べる→食べない |
| 三类 | する→しない；来る→こない | 勉強する→勉強しない |

「ある」的否定是「ない」。

> 今日はテレビを見ない。

今天不看电视。

## て形

二类动词去掉「る」加「て」；三类动词「する」变为「して」，「来る」变为「来て（きて）」。一类动词按辞书形词尾变化：

| 辞书形词尾 | て形 | 例子 |
| --- | --- | --- |
| う、つ、る | って | 買う→買って |
| む、ぶ、ぬ | んで | 読む→読んで |
| く | いて | 書く→書いて |
| ぐ | いで | 泳ぐ→泳いで |
| す | して | 話す→話して |

「行く」是例外：行って。

> 朝ご飯を食べて、学校へ行きます。

吃过早饭后去学校。

## た形

た形的构成与て形按同一组词尾变化，但将「て／で」分别换成「た／だ」。二类、三类动词的变化也分别对应「て形」。

| 类别或词尾 | た形 | 例子 |
| --- | --- | --- |
| 一类：う、つ、る | った | 買う→買った |
| 一类：む、ぶ、ぬ | んだ | 読む→読んだ |
| 一类：く | いた | 書く→書いた |
| 一类：ぐ | いだ | 泳ぐ→泳いだ |
| 一类：す | した | 話す→話した |
| 二类 | 去る＋た | 食べる→食べた |
| 三类 | する→した；来る→来た（きた） | 勉強する→勉強した |

「行く」是例外：行った。

> 昨日、友達と映画を見た。

昨天和朋友看了电影。

## 可能形

可能形表示能力或实现某动作的可能性。

| 类别 | 构成 | 例子 |
| --- | --- | --- |
| 一类 | 词尾改为同一行「え」段＋る | 書く→書ける；読む→読める |
| 二类 | 去掉「る」＋られる | 食べる→食べられる |
| 三类 | する→できる；来る→来られる（こられる） | 勉強する→勉強できる |

口语中二类、三类可能形有时省略「ら」，如「食べれる、来れる」；正式表达和学习标准活用时使用「食べられる、来られる」。

## 被动形

被动形表示承受动作。

| 类别 | 构成 | 例子 |
| --- | --- | --- |
| 一类 | 词尾改为「あ」段＋れる；「う」改为「わ」＋れる | 書く→書かれる；買う→買われる |
| 二类 | 去掉「る」＋られる | ほめる→ほめられる |
| 三类 | する→される；来る→来られる（こられる） | 招待する→招待される |

## 使役形

使役形表示使某人做某事，或允许、让某人做某事。

| 类别 | 构成 | 例子 |
| --- | --- | --- |
| 一类 | 词尾改为「あ」段＋せる；「う」改为「わ」＋せる | 書く→書かせる；買う→買わせる |
| 二类 | 去掉「る」＋させる | 食べる→食べさせる |
| 三类 | する→させる；来る→来させる（こさせる） | 勉強する→勉強させる |

## 使役被动形

使役被动形表示被迫或不得不做某事。常见完整形式由使役形再变为被动形；一类动词口语中常用缩约形式「～される」。

| 类别 | 完整形式 | 例子 |
| --- | --- | --- |
| 一类 | 词尾改为「あ」段＋せられる；「う」改为「わ」＋せられる | 書く→書かせられる；買う→買わせられる |
| 一类口语缩约 | 词尾改为「あ」段＋される（「す」结尾等需按实际形式判断） | 書く→書かされる |
| 二类 | 去掉「る」＋させられる | 食べる→食べさせられる |
| 三类 | する→させられる；来る→来させられる（こさせられる） | 勉強する→勉強させられる |

使役被动形本质是动词先变成使役形「~させる」，然后再将使役形变为被动「~させられる」。

而一类中「あせられる」中「せら」连读为「さ」变为「あされる」。但是**以「す」结尾的一类动词不能缩写！**如果缩写会造成发音重复（变成 「さされる」）

## 命令形

命令形直接要求对方行动，语气较强；一般请求常用「～てください」。

| 类别 | 构成 | 例子 |
| --- | --- | --- |
| 一类 | 词尾改为同一行「え」段 | 書く→書け；読む→読め |
| 二类 | 去掉「る」＋ろ（也有「よ」） | 食べる→食べろ |
| 三类 | する→しろ／せよ；来る→来い（こい） | 早く来い |

## 意志形

意志形表示说话人的意愿，也可用于较随意的提议。

| 类别 | 构成 | 例子 |
| --- | --- | --- |
| 一类 | 词尾改为同一行「お」段＋う | 書く→書こう；読む→読もう |
| 二类 | 去掉「る」＋よう | 食べる→食べよう |
| 三类 | する→しよう；来る→来よう（こよう） | 勉強する→勉強しよう |

> そろそろ帰ろう。

差不多该回去了吧。

## 本篇总结

辞书形词尾帮助判断动词类别：一类词尾在「う」段，二类通常为「い／え」段＋る，三类为「する、来る」及复合形式。确认类别后，分别按规则构成ます形、ない形、て形、た形、可能形、被动形、使役形、使役被动形、命令形和意志形。需单独记住「帰る」等一类「る」动词和「行く」的て形、た形例外。
