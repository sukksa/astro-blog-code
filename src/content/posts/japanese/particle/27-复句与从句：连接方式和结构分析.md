# 复句与从句：连接方式和结构分析

一个句子可以由多个小句组成。能够独立表达主要陈述的部分是主句；补充时间、原因、条件、引用内容或名词信息的部分是从句。日语的谓语通常放在所在小句的末尾，连接形式和助词帮助读者判断各部分之间的关系。

> [雨が降っていたので]、[試合は中止になりました]。

因为一直在下雨，比赛取消了。

「雨が降っていたので」交代原因，「試合は中止になりました」是主要陈述。长句阅读时，先找各自的谓语和连接形式，再判断哪一部分修饰哪一个词或句子。

## 用「て形」连接动作和状态

动词、形容词和名词的て形都可以把两个以上的小句连在一起。它本身不只表示“然后”，具体关系要根据词类、语序和上下文判断。

| 常见关系 | 结构特点 |
| --- | --- |
| 动作先后 | 同一主体依次做几件事，动作顺序通常自然可知 |
| 并列或伴随状态 | 连接同时成立的状态、性质、动作或方法 |
| 原因与结果 | 前项说明后项发生的原因或背景 |

### 表示动作先后

同一主体先后做几件事时，前面的动词使用て形，句末动词表达整句的时态和语体。需要连接多个动作时，可以连续使用て形。

> 朝起きて、顔を洗って、朝ご飯を食べます。

早上起床、洗脸，然后吃早饭。

动作顺序通常按事情发展的自然次序理解。て形本身不明确标出“前项完全结束后，后项才开始”；需要突出前项完成是后项的起点时，可以用「てから」。

### 连接并列或伴随状态

て形也可以把两个状态、性质、动作或方法放在一起说明。连接的内容不一定是严格的先后关系。

> 父は東京に住んでいて、母は大阪で働いています。

父亲住在东京，母亲在大阪工作。

> 毎日、歩いて学校へ行きます。

我每天走路去学校。

第一句用て形并列说明两人的状态；第二句说明去学校时采用的方式。若两个小句的主语不同，通常要在各自的小句中明确标出主语。

连接形容词或名词的并列状态时，一类形容词用「〜くて」，二类形容词和名词用「〜で」：

> この部屋は広くて、きれいです。

这个房间又宽敞又干净。

> 田中さんは親切で、日本語が上手です。

田中先生人很亲切，日语也很好。

### 表示原因或背景

某个事件或状态可以作为后项结果的原因或背景。原因关系主要根据语境理解，て形不直接标出原因的强弱。

> 大雨が降って、試合は中止になりました。

下了大雨，比赛取消了。

需要注意的是，**用て形表示原因时，后句一般只能接既成事实、自然结果或无意志的状态变化，不能接说话人的意志、请求、命令或劝诱**（例如不能说 ×`雨が降って、傘を持って行ってください`）。如果要明确交代原因，或用理由引出请求、判断、劝诱等内容，应使用「から」或「ので」。

## 「たり」：举出若干代表性动作或状态

动词た形后接「り」构成「たり」，列举动作时常用「动词たり、动词たりする」。列举的动作是代表性例子，通常暗示还有其他活动；句末「する」负责表达时态和语体。

| 用法 | 形式 |
| --- | --- |
| 列举代表性动作 | 动词た形＋り、动词た形＋り＋する |
| 表示两种状态交替反复 | 动词た形＋り、动词た形＋り＋する／している |
| 列举或交替形容词、名词状态 | 一类形容词「〜かったり〜かったり」／二类形容词・名词「〜だったり〜だったり」＋する／です |

> 週末は本を読んだり、映画を見たりします。

周末我会看看书、看看电影之类的。

> 雨が降ったりやんだりしています。

雨时下时停。

> 最近の天気は暑かったり寒かったりです。

最近的天气忽冷忽热。

「たり」不表示动作一定按列出的顺序发生。说话人要表达的是几种典型活动或反复变化，而不是完整、严格的步骤清单。

## 「し」：并列事实、特点或理由

「し」可以列举多个事实、特点或理由。它常用于说明做出判断的依据，也可以只列出一项，并让听者理解还有其他相关理由。

| 前接内容 | 接续形式 |
| --- | --- |
| 动词 | 普通形＋し，如「行くし」「行ったし」 |
| 一类形容词 | 普通形＋し，如「安いし」 |
| 二类形容词 | 普通形＋し，如「静かだし」「静かではないし」 |
| 名词 | 普通形＋し，如「休みだし」「休みだったし」 |

礼貌表达中，动词和形容词、名词也可以接「ますし／ですし」，如「行きますし」「安いですし」「静かですし」「休みですし」。

> この店は駅に近いし、料理もおいしいし、よく来ます。

这家店离车站近，饭菜也好吃，所以我常来。

> この町は静かだし、スーパーも近いです。

这个城镇很安静，超市也近。

> 時間も遅いし、そろそろ帰りましょう。

时间也不早了，我们差不多该回去了吧。

使用「し」时，小句内部常把「が」「を」等助词换成「も」，以加强“不仅……而且……”的累加语气。「し」连接的内容可以共同支持后句，但不一定都要解释成直接原因，有时只是补充列举几个特点。

## 「ながら」：同一主体同时做两件事

动词ます形去掉「ます」后接「ながら」，表示同一主体同时进行两个动作。前面的动作通常作为伴随动作（一般使用可持续进行的动词），后面的谓语说明主要动作。

| 辞书形 | ます形词干 | 接「ながら」 |
| --- | --- | --- |
| 聞く | 聞き | 聞きながら |
| 食べる | 食べ | 食べながら |
| する | し | しながら |

> 音楽を聞きながら、宿題をしています。

我一边听音乐，一边做作业。

两个动作必须能由同一主体同时进行。主要动作放在句末；若前后动作分别由不同主体完成，应改用「〜ている間（に）」等适合的连接结构（如 `私が勉強している間、弟はテレビを見ていました`）。

「ながら」也会出现在「知っていながら知らないふりをする」这类表达中，表示明知某事却做出相反表现。这种用法带有对照或让步意味，和动作同时进行的基本用法不同。

## 从句常见的几种作用

从句与主句的关系，可以先按它在句子里承担的作用来识别：

| 从句作用 | 常见形式 | 主要说明内容 |
| --- | --- | --- |
| 修饰名词 | 小句按词类采用普通形或相应连体形式＋名词 | 哪一个人、物或事情 |
| 表示时间 | 「とき」「前に」「後で」「てから」「間（に）」等 | 事件发生的时间或先后 |
| 表示原因 | 普通形＋「から／ので」；名词、二类形容词非过去肯定＋「だから／なので」 | 后项发生的理由或背景 |
| 表示条件 | 条件形式＋主句，如「行くと／行けば／行ったら／行くなら」 | 后项成立的条件 |
| 表示引用或疑问内容 | 普通形（名词、二类形容词非过去肯定含「だ」）＋「と」；疑问词＋「か」／「〜かどうか」（名词、二类形容词不加「だ」） | 说话、思考或判断的具体内容 |

### 名词修饰从句

修饰名词的小句紧放在名词前，整个名词短语再作为主句的成分。**动词和一类形容词直接修饰名词，绝对不能像中文“的”那样在中间加「の」**（不能说 ×`昨日買ったの本`）。

> [田中さんが昨日買った]本を読みました。

我读了田中先生昨天买的书。

### 时间从句

「动词普通形＋とき」说明主句动作发生的时间。动词使用辞书形还是た形，有时会改变两个动作的先后关系：

> 日本へ来るとき、空港で写真を撮りました。

来日本的时候，我在机场拍了照片。（拍照发生在来日本的途中或到达之前。）

> 日本へ来たとき、空港で写真を撮りました。

（刚）到日本的时候，我在机场拍了照片。（拍照发生在到达日本之后、刚抵达机场时。）

一类形容词直接接「とき」，二类形容词用「なとき」，名词用「のとき」，如「若いとき」「静かなとき」「学生のとき」。

其他常见时间关系形式包括「辞书形／名词の＋前に」「た形／名词の＋後で」「て形＋から」，以及「ている形＋間（に）」和「名词＋の間（に）」。其中，「間」强调动作或状态在整段时间内持续，「間に」则强调在该时间段内的某个时刻发生了某件事：

> 夏休みの間、ずっとアルバイトをしていました。

暑假期间一直在打工。

> 寝ている間に、雨が降ってきました。

睡觉的时候下起雨来了。

### 原因与条件从句

动词和一类形容词普通形后可以接「から／ので」；二类形容词、名词的非过去肯定形式分别接「だから／なので」。否定或过去形式保留相应普通形，如「静かではないので」「学生だったから」。礼貌表达也可以使用「ですから／ですので」「ますから／ますので」。

> 時間がなかったので、タクシーで行きました。

因为没有时间，所以坐出租车去了。

「から」主观色彩较强，常用于个人理由或主张，后句可以接命令、请求、劝诱或推测；「ので」语气温和、偏客观，常用于说明事实或委婉提出请求。

条件从句说明后项成立的假设或前提。不同条件形式所表达的条件关系和后续内容有限制，不能仅按中文“如果”互换：

| 条件形式 | 核心特点 | 常见限制或侧重点 |
| --- | --- | --- |
| 〜と | 恒常规律、自然结果或紧接发生的动作 | 后句通常不接说话人的意志、请求或命令 |
| 〜ば | 一般性的假定条件 | 强调“只要满足前项，就能产生后项” |
| 〜たら | 具体的一次性条件或动作完成后的结果 | 使用范围最广，后句可接请求、劝诱或过去事实 |
| 〜なら | 承接对方话题或既定前提提出建议 | 常用于“如果是那样的话……”的语境 |

> 時間があったら、いっしょに昼ご飯を食べましょう。

如果有时间，我们一起吃午饭吧。

### 引用和疑问内容从句

引用的陈述内容常用普通形加「と」，再接「言う」「思う」等谓语；嵌入句中的疑问内容可以用「疑问词＋か」表示，而**不含疑问词的一般疑问句则用「〜かどうか」表示“是否……”**。

> 田中さんは来週帰ると言っていました。

田中先生说下周回来。

> 田中さんがいつ帰るか、分かりません。

我不知道田中先生什么时候回来。

> 田中さんが来るかどうか、分かりません。

我不知道田中先生来不来。

需要注意的是，名词和二类形容词的现在肯定形式接「か」或「かどうか」时，**通常不加「だ」**（如 `本当かどうか分かりません`，不说 ×`本当だかどうか`）。引用或疑问内容本身可以带有自己的主语、对象和其他修饰语，分析时要确认助词属于内层小句，还是标记整个内容在外层句中的作用。

## 从句里的「は」和「が」

从句内部的助词按从句自身的结构判断。**单纯标记从句内部主语时用「が」（名词修饰从句中也可用「の」），只有需要强调对比时才在从句里使用「は」**；主句则可另用「は」提出全句话题。

> 私は[妹が作った]ケーキを食べました。

我吃了妹妹做的蛋糕。

「私は」提出主句话题；「妹が」是名词修饰从句内部的主语（此处不能换成「妹は」）。

> コーヒーは飲むが、紅茶は飲まない人もいます。

也有人喝咖啡，但不喝红茶。

这里两个「は」表达对比；句末的「が」连接前后内容，表示转折。它与小句内部标记主语的「が」作用不同。

## 拆解多层长句

遇到包含多个修饰和连接的小句时，可以按下面的次序阅读：

1. 先找句末谓语，确定整句话的主要陈述。
2. 找出「て、たり、し、ながら、ので、から、が」等连接形式，划分小句。
3. 找出从句修饰的名词或句子成分，确认修饰范围。
4. 分别判断每个小句的主语、对象、时间、原因等关系（留意日语常省略主语「私」以及宾语话题化），再组合整体意思。

> 昨日、駅で買った本は、知らない言葉が多かったので、辞書を使いながら読みました。

昨天在车站买的那本书里有很多不认识的词，所以我一边用词典一边读了这本书。

| 句子部分 | 作用 |
| --- | --- |
| 昨日、駅で買った | 修饰「本」，说明是哪一本书 |
| 本は | 提出主句话题；在语法上同时也是句末「読みました」的宾语（宾语话题化） |
| 知らない言葉が多かったので | 说明后续阅读时使用词典的原因；「が」标记从句主语 |
| 辞書を使いながら | 表示伴随动作；与「読みました」同属省略了的主体「私」 |
| 読みました | 句末主要谓语，说明主句动作及礼貌过去时 |

先划清小句边界，就能看出每个助词和活用形式的作用；再按“修饰关系—连接关系—主要陈述”的顺序组合翻译，长句就不必从头到尾逐词硬译。

## 本篇总结

- 主句承担全句主要陈述；从句补充时间、原因、条件、引用内容或名词信息。句末谓语通常是判断全句主干的重要线索。
- て形可表达动作顺序、并列或伴随状态，也可在语境中表示原因（但后句通常不接意志、请求或命令）；它本身不固定等于某一个中文连词。
- 「たり」列举代表性动作或状态交替；「し」列举事实、特点或理由（常搭配「も」）；「ながら」常表示同一主体同时做两件事，后项是主要动作。
- 从句通常使用符合其连接形式的谓语形式；时间、原因、条件和引用/疑问关系各有不同接续规则，如一般疑问从句用「かどうか」且名词、二类形容词前不加「だ」。
- 从句内部单纯标记主语用「が」，表达对比用「は」；需结合所在小句和语义焦点判断。
- 拆长句时，先找主句谓语，再划分连接的小句、确认修饰范围，最后还原各小句省略的主语和句法关系。
