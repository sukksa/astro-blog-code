# 动词形态：一张表看懂十三个形态

> **一句话**：日语动词的形态不是十三个独立的东西，而是**同一个词干 ＋ 不同词尾**。
> 记住五段派生，等于记住了大半个形态表。

---

## 一、动词分类

| 类别 | 判别方法 | 例 |
|---|---|---|
| **三类** | 「する」「来る」及其复合词 | する、来る、勉強する、連絡する |
| **二类** | る结尾，且る前是**い段或え段** | 食べる、見る、起きる、寝る、教える |
| **一类** | 其余全部 | 書く、話す、待つ、死ぬ、遊ぶ、読む、買う、帰る |

### 例外（长得像二类，实际是一类）

**帰る・入る・走る・知る・切る・要る・減る・蹴る**

这几个的る前虽是い段或え段，但属于一类动词，必须单独记。

---

## 二、五段派生（一类动词的核心）

一类动词的所有形态都从同一个词干派生，按「段」变化。

| 段 | 词干（書く） | 派生的形态 |
|---|---|---|
| **あ段** | 書か | ない形 書か＋ない／受身 書か＋れる／使役 書か＋せる |
| **い段** | 書き | ます形 書き＋ます |
| **う段** | 書く | 辞書形（原形） |
| **え段** | 書け | 可能形 書け＋る／命令形 書け／ば形 書け＋ば |
| **お段** | 書こ | 意向形 書こ＋う |

> **记住这一张表，等于记住八种形态。**
>
> 特别注意 **え段**：同一个「書け」加上不同词尾，就是三种形态。
> 它也是唯一一个「一个词干管三种形态」的段，所以最容易混。

---

## 三、各形态的构成

### ます形

| 类别 | 规则 | 例 |
|---|---|---|
| 一类 | 词尾由う段变い段 ＋ ます | 書く→書き**ます**、話す→話し**ます**、待つ→待ち**ます** |
| 二类 | る → ます | 食べる→食べ**ます**、見る→見**ます** |
| 三类 | する→します、来る→来ます | 勉強する→勉強**します** |

### て形

**一类动词的音便（五种）**

| 词尾 | て形 | 例 |
|---|---|---|
| **う・つ・る** | って | 買う→買**って**、待つ→待**って**、帰る→帰**って** |
| **む・ぶ・ぬ** | んで | 読む→読**んで**、遊ぶ→遊**んで**、死ぬ→死**んで** |
| **く** | いて | 書く→書**いて** |
| **ぐ** | いで | 泳ぐ→泳**いで** |
| **す** | して | 話す→話**して** |

**例外**：行く → 行**って**（不是 行いて）

**二类・三类**：食べる→食べ**て**／する→**して**、来る→**来て**

> **记忆分组**：う・つ・る → って／む・ぶ・ぬ → んで／**く・ぐ → いて・いで**／す → して
>
> 「く・ぐ」只有两个词尾，单独拎出来记：く→いて（清音）、ぐ→いで（浊音）。
> 这两个是唯一的「い音便」，不参与 って／んで 的分组。

### た形

**规则与て形完全相同**，只把 `て`→`た`、`で`→`だ`。

買って→買った／読んで→読んだ／書いて→書いた／泳いで→泳いだ／話して→話した／食べて→食べた

### ない形

| 类别 | 规则 | 例 |
|---|---|---|
| 一类 | 词尾由う段变あ段 ＋ ない | 書く→書か**ない**、買う→買わ**ない**、帰る→帰ら**ない** |
| 二类 | る → ない | 食べる→食べ**ない** |
| 三类 | する→しない、来る→来ない | |

> **注意**：以 `う` 结尾的动词变 `わ`，不是 `あ`。買う → 買**わ**ない（× 買あない）

### 辞書形

即原形。用于 `〜ことができる`、`〜前に`、`〜つもりだ`、`〜ながら` 等句型。

### 可能形

| 类别 | 规则 | 例 |
|---|---|---|
| 一类 | 词尾由う段变**え段** ＋ る | 書く→書け**る**、待つ→待て**る**、読む→読め**る**、持つ→持て**る** |
| 二类 | る → られる | 食べる→食べ**られる** |
| 三类 | する→**できる**、来る→来られる | |

> `する` 的可能形是 **できる**，不是 される（される 是受身）。

### 可能形的口语变体：ら抜き言葉

二类动词和 `来る` 的可能形，口语里常把 `ら` 省掉。

| 标准形 | ら抜き形 |
|---|---|
| 食べられる | 食べ**れる** |
| 見られる | 見**れる** |
| 起きられる | 起き**れる** |
| 来られる | 来**れる** |

**适用范围**：只有**二类动词**和 `来る`。一类动词不受影响 —— 書ける、行ける 本来就没有 `ら`。

**关键限制：只有可能形能省，受身形不能省。**

| | 形式 | 能不能省 `ら` |
|---|---|---|
| 可能 | 食べられる → 食べれる | ○ 口语可以 |
| 受身 | 食べられる（被吃） | × 必须是 食べられる |

> **为什么这个说法会流行**：二类动词的可能形和受身形本来同形（都是 食べられる），
> 容易歧义。省掉 `ら` 之后，`食べれる` 只表示可能，反而更清楚。
>
> 但 `ら抜き言葉` 仍属**口语**，正式书面和敬语场合不用。

### 意向形

| 类别 | 规则 | 例 |
|---|---|---|
| 一类 | 词尾由う段变**お段** ＋ う | 書く→書こ**う**、待つ→待と**う**、帰る→帰ろ**う** |
| 二类 | る → よう | 食べる→食べ**よう** |
| 三类 | する→しよう、来る→来よう | |

### 命令形・禁止形

**命令形**

| 类别 | 规则 | 例 |
|---|---|---|
| 一类 | 词尾由う段变**え段** | 書**け**、待**て**、帰**れ** |
| 二类 | る → ろ | 食べ**ろ** |
| 三类 | する→しろ、来る→来い | |

**禁止形**：辞書形 ＋ な —— 書く**な**、食べる**な**、する**な**、来る**な**

### ば形（条件形）

| 类别 | 规则 | 例 |
|---|---|---|
| 一类 | 词尾由う段变**え段** ＋ ば | 書**けば**、待**てば**、帰**れば** |
| 二类 | る → れば | 食べ**れば** |
| 三类 | する→すれば、来る→来れば | |

### 受身形

| 类别 | 规则 | 例 |
|---|---|---|
| 一类 | 词尾由う段变**あ段** ＋ れる | 書く→書**かれる**、待つ→待**たれる**、読む→読**まれる** |
| 二类 | る → られる | 食べる→食べ**られる** |
| 三类 | する→される、来る→来られる | |

用法：直接受身／持ち主受身／被害受身／客观叙述（详见「视点」一篇）

> 二类动词的受身形与可能形同形（食べられる），靠语境区分。

### 使役形

| 类别 | 规则 | 例 |
|---|---|---|
| 一类 | 词尾由う段变**あ段** ＋ せる | 書く→書**かせる**、待つ→待**たせる**、読む→読**ませる** |
| 二类 | る → させる | 食べる→食べ**させる** |
| 三类 | する→させる、来る→来させる | |

助词：他动词用 `に`（子供**に**野菜を食べさせる）／自动词用 `を`（学生**を**立たせる）

> 受身形是 あ段＋**れる**，使役形是 あ段＋**せる**。同段不同尾，最容易混。

### 使役受身

| 类别 | 规则 | 例 |
|---|---|---|
| 一类 | あ段＋される（缩略）／あ段＋せられる | 書く→書**かされる**／書**かせられる** |
| 二类 | させられる | 食べる→食べ**させられる** |
| 三类 | させられる | する→**させられる** |

意义：被迫做某事。形式关系是 `させる` ＋ `れる` ＝ `させられる`

> 以 `す` 结尾的动词不能缩略：話させられる（× 話さされる）

## 四、形态总表

| 形态 | 一类（書く） | 二类（食べる） | 三类（する／来る） |
|---|---|---|---|
| ます形 | 書きます | 食べます | します／来ます |
| て形 | 書いて | 食べて | して／来て |
| た形 | 書いた | 食べた | した／来た |
| ない形 | 書かない | 食べない | しない／来ない |
| 辞書形 | 書く | 食べる | する／来る |
| 可能形 | 書ける | 食べられる | できる／来られる |
| 意向形 | 書こう | 食べよう | しよう／来よう |
| 命令形 | 書け | 食べろ | しろ／来い |
| 禁止形 | 書くな | 食べるな | するな／来るな |
| ば形 | 書けば | 食べれば | すれば／来れば |
| 受身形 | 書かれる | 食べられる | される／来られる |
| 使役形 | 書かせる | 食べさせる | させる／来させる |
| 使役受身 | 書かされる | 食べさせられる | させられる／来させられる |

## 五、两组最容易混的形态

### 可能形 vs 受身形

| | 形式 | 例 | 意思 |
|---|---|---|---|
| 可能形 | **え段** ＋ る | 書**け**る | 能写 |
| 受身形 | **あ段** ＋ れる | 書**か**れる | 被写 |

只差一个段：え段是「能」，あ段是「被」。

### 命令形 vs 意向形

| | 形式 | 例 | 意思 |
|---|---|---|---|
| 命令形 | **え段** | 書**け** | 写！（短促） |
| 意向形 | **お段** ＋ う | 書**こ**う | 写吧（带う） |

记法：**命令形是短促的一个词，意向形一定带 `う`。**

## 六、易错点

1. **一类动词的例外**：帰る・入る・走る・知る・切る・要る・減る 属一类
2. **て形音便**：うつる→って、むぶぬ→んで、くぐ→いて／いで、す→して
3. **行く → 行って**（音便例外）
4. **ない形**：う → わ（買う→買わない）
5. **する的可能形是 できる**，不是 される
6. **可能形用え段，受身形用あ段** —— 不要混
7. **命令形用え段，意向形用お段** —— 不要混
8. **二类动词受身形与可能形同形**（食べられる），靠语境区分
9. **ら抜き言葉 只用于可能形**：食べれる（可能，口语）／食べられる（受身，不能省）
10. **受身形与使役形同用あ段**：書か＋**れる**（受身）／書か＋**せる**（使役），只差词尾

## 九、补充：读小说时怎么理解（额外）

以下不属于教材语法点，是读小说、漫画、游戏时的额外视角。

**① 形态本身就带着语体信息**

| 形态 | 常见场合 |
|---|---|
| ます形 | 礼貌对话、对读者说话、说明文 |
| 辞書形・た形・ない形 | 小说旁白、内心独白、关系亲近的对话 |
| 命令形 | 漫画对话、紧急场面、男性角色语 |
| 禁止形 | 「触るな！」「心配するな」—— 强烈制止或安慰 |

读到旁白突然从普通形切到ます形，往往是叙述者在「对读者说话」，或者是角色在切换礼貌程度。

**② 命令形和禁止形在漫画里极多**

- 行け！／やめろ！／触るな！／心配するな。

它们几乎只出现在对话里，而且是短句。看到这类形态，先判断是谁在对谁说 ——
这决定了它是粗暴的命令，还是关心的劝阻（「心配するな」常是安慰）。

**③ 意向形不只是「一起做」**

- そろそろ行こう。（提议）
- よし、やろう。（决心）
- 何か食べようか。（自我提议）

小说里 `〜よう` 常出现在角色的心理独白，表示「下定决心」的那一刻。

**④ ら抜き言葉 是「口语身份」的标记**

- 食べれる（标准：食べられる）
- 見れる（标准：見られる）
- 来れる（标准：来られる）

构成本身在「可能形」一节已讲过。这里要说的是它的**语体信号**：

它几乎只出现在**对话、漫画、年轻人之间、内心独白**里。正式书面、新闻报道、敬语场合一律不用。

所以读到 `食べれる`，可以推断：这句话是口语，说话人不太正式，或者场景比较轻松。
反过来说，如果一个角色平时说话很规矩，突然冒出 ら抜き，那可能是他放松了，或者在刻意显得随意。

**⑤ て形是连接长句的主力**

小说里一句话套好几个动作，全靠て形串起来：

> 彼は立ち上がって、窓を開けて、煙草に火をつけた。

读这种句子时，先按て形切分成几个动作，再判断先后和主次。
て形还能表原因（遅くなってすみません）、表状态（眼鏡をかけて本を読む），
具体是哪种，要看后项。
